    17.4. تحويل البرامج النصية MySQL إلى البرامج النصية PostgreSQL

    • يتم نسخ المجلد [1] الخاص بالنصوص البرمجية MySQL (Ctrl-C / Ctrl-V)، ثم يتم تغيير أسماء الملفات دون تغيير محتواها؛

    17.4.1. الوحدة النمطية [pgres_module]

    هذه الوحدة هي نسخة من الوحدة [mysql_module] (انظر الفقرة |النص البرمجي [mysql-04]: تنفيذ ملف أوامر SQL|). يتم تغيير الاستيرادات:

    بدلاً من:

    
# عمليات الاستيراد
from mysql.connector import DatabaseError, InterfaceError
from mysql.connector.connection import MySQLConnection
from mysql.connector.cursor import MySQLCursor

    نكتب:

    
# عمليات الاستيراد
from psycopg2 import DatabaseError, InterfaceError
from psycopg2.extensions import connection, cursor

    كانت توقيعات الدالة [afficher_infos] كما يلي:

    
def afficher_infos(curseur: MySQLCursor):

    وأصبحت:

    
def afficher_infos(curseur: cursor)

    كان توقيع الدالة [execute_list_of_commands] كما يلي:

    
def execute_list_of_commands(connexion: MySQLConnection, sql_commands: list,
                             suivi: bool = False, arrêt: bool = True, with_transaction: bool = True)

    وتصبح:

    
def execute_list_of_commands(connexion: connection, sql_commands: list,
                             suivi: bool = False, arrêt: bool = True, with_transaction: bool = True):

    بخلاف ذلك، لا يتغير أي شيء آخر.

    17.4.2. البرنامج النصي [pgres_01]

    البرنامج النصي [pgres_01] هو نسخة من البرنامج النصي [mysql_01] (انظر الفقرة |البرنامج النصي [mysql-01]: الاتصال بقاعدة بيانات MySQL - 1|). يتم إجراء التعديلات التالية عليه:

    بدلاً من:

    
# استيراد الوحدة النمطية mysql.connector
from mysql.connector import connect, DatabaseError, InterfaceError

    نكتب:

    
# استيراد الوحدة النمطية psycopg2
from psycopg2 import connect, DatabaseError, InterfaceError

    لا يتغير الباقي. النتائج هي نفسها كما في حالة MySQL.

    # تقوم بتسجيل الدخول ثم تسجيل الخروج (login,pwd) من قاعدة البيانات [database] على الخادم [host]
    # يطلق الاستثناء DatabaseError في حالة وجود مشكلة
    connexion = None
    try:
        # تسجيل الدخول

        # يتم إغلاق الاتصال إذا كان قد تم فتحه

    هنا، تختلف النتيجة عن تلك التي تم الحصول عليها باستخدام MySQL. إذا تم تنفيذ البرامج النصية في نفس الظروف، أي بعد تنفيذ البرنامج النصي بدون معاملة، نحصل على النتائج التالية:

    • مع MySQL، تكون الجدولة [personnes] فارغة؛
    • مع PostgreSQL، الجدول [personnes] ليس فارغًا؛

    ويكمن الاختلاف في الطرق المختلفة التي يستخدمها هذان البرنامجان SGBD لإلغاء المعاملة:

    • لا تلغي MySQL الأوامر [drop table] و [create table]. وبذلك يصبح الجدول [personnes] فارغًا؛
    • PostgreSQL يلغي الأوامر [drop table] و [create table]. نجد الجدول في الحالة التي كان عليها قبل تنفيذ البرنامج النصي مع المعاملة؛

    17.4.6. البرنامج النصي [pgres_05]

    البرنامج النصي [pgres_05] هو نسخة من البرنامج النصي [mysql_05] (انظر الفقرة |البرنامج النصي [mysql-05]: استخدام الاستعلامات المعلمة|). تم تعديل البرنامج النصي على النحو التالي:

    بدلاً من:

    
# عمليات الاستيراد
from mysql.connector import connect, DatabaseError, InterfaceError

    نكتب:

    
# عمليات الاستيراد
from psycopg2 import connect, DatabaseError, InterfaceError

    لا يتغير الباقي.

    17.5. الخلاصة

    تم تحويل البرامج النصية MySQL إلى البرامج النصية PostgreSQL بسهولة نسبية. وهذا استثناء. لا يدعم كل من SGBD نفس قواعد تسمية الكائنات الموجودة في SQL (قواعد البيانات، الجداول، الأعمدة، القيود، أنواع البيانات...)، كما أن امتدادات SQL غير متوافقة... لضمان عملية نقل بسيطة، يجب الالتزام في كلتا الحالتين بمعيار SQL دون محاولة استخدام الامتدادات الخاصة بـ SGBD. ويحدث ذلك على حساب الأداء.
