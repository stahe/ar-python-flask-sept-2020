    18. كتابة كود مستقل عن SGBD

    لقد رأينا سابقًا أنه في بعض الحالات كان من الممكن الترحيل ببساطة من كود Python المكتوب لـ SGBD و MySQL إلى كود مكتوب لـ SGBD و PostgreSQL. في هذا الفصل، نوضح كيفية تنظيم هذا النهج. وتصبح البنية المقترحة كما يلي:

    نرغب في أن يتم اختيار الموصل، وبالتالي اختيار SGBD، عن طريق التكوين دون الحاجة إلى إعادة كتابة البرنامج النصي. ونذكر أن هذا ممكن فقط في الحالات التي لا يستخدم فيها البرنامج النصي ملحقات خاصة بـ SGBD.

    وستكون بنية البرامج النصية كما يلي:

    تستند البرامج النصية [any_xx] إلى البرامج النصية التي تمت دراستها سابقًا لـ SGBD و MySQL و PostgreSQL. لن نعيد استعراضها جميعًا. سنركز على البرنامج النصي [any_04] الذي يُعد الأكثر تعقيدًا. نذكر أن هذا البرنامج النصي يُنفذ الأوامر SQL الواردة في الملف [data/commandes.sql] التالي:

    النص البرمجي [any_04] الذي ينفذ ملف الأوامر SQL [data/commandes.sql] هو التالي:

    
# يتم تكوين التطبيق
import config

config = config.configure()

# تم تكوين مسار النظام (syspath) - يمكن الآن إجراء عمليات الاستيراد
import importlib
import sys

# التحقق من صحة صيغة الاستدعاء
# argv[0] sgbd_name صحيح / خطأ
# يلزم وجود 3 معلمات
args = sys.argv
erreur = len(args) != 3
if not erreur:
    # نسترد المعلمتين اللتين تهماننا
    sgbd_name = args[1].lower()
    with_transaction = args[2].lower()
    # التحقق من المعلمتين
    erreur = (with_transaction != "true" and with_transaction != "false") \
             or sgbd_name not in config["sgbds"].keys()
# خطأ؟
if erreur:
    print(f"syntaxe : {args[0]} (1) sgbd_name (2) true / false")
    sys.exit()

# تكوين sgbd_name
sgbd_config = config["sgbds"][sgbd_name]
# موصل sgbd_name
sgbd_connector = importlib.import_module(sgbd_config["sgbd_connector"])
# مكتبة الوظائف
lib = importlib.import_module(sgbd_config["sgbd_fonctions"])


# حساب نص للعرض
with_transaction = with_transaction == "true"
if with_transaction:
    texte = "avec transaction"
else:
    texte = "sans transaction"

# العرض
commands_filename=config['commands_filename']
print("--------------------------------------------------------------------")
print(f"Exécution du fichier SQL {commands_filename} {texte}")
print("--------------------------------------------------------------------")

# تنفيذ الأوامر SQL من الملف
connexion = None
try:
    # تسجيل الدخول
    connexion = sgbd_connector.connect(
        host=sgbd_config['host'],
        user=sgbd_config['user'],
        password=sgbd_config['password'],
        database=sgbd_config['database'])
    # تنفيذ ملف الأوامر SQL
    erreurs = lib.execute_file_of_commands(sgbd_connector, connexion, commands_filename, suivi=True, arrêt=False,
                                           with_transaction=with_transaction)
except (sgbd_connector.InterfaceError, sgbd_connector.DatabaseError) as erreur:
    print(f"L'erreur suivante s'est produite : {erreur}")
finally:
    # إغلاق الاتصال
    if connexion:
        connexion.close()

# عرض عدد الأخطاء
print("--------------------------------------------------------------------")
print(f"Exécution terminée")
print("--------------------------------------------------------------------")
print(f"Il y a eu {len(erreurs)} erreur(s)")
# عرض الأخطاء
for erreur in erreurs:
    print(erreur)

    تعليقات

    • الأسطر 1-4: يتم استرداد تكوين التطبيق [config]؛
    • الأسطر 10-21: يتم استدعاء البرنامج النصي بمعلمتين [sgbd_name with_transaction]:
      • [sgbd_name]: اسم ملف SGBD المراد استخدامه؛
      • [with_transaction]: True إذا كنا نريد تنفيذ ملف الأوامر SQL ضمن معاملة، و False بخلاف ذلك؛
    • الأسطر 10-25: يتم استرداد المعلمات والتحقق منها؛
    • السطر 28: تكوين ملف SGBD المختار؛
    • السطر 30: يتم استيراد موصل ملف SGBD المختار. ويُستخدم في ذلك المكتبة [importlib] (السطر 7) التي تسمح باستيراد وحدة نمطية اسمها موجود في متغير. نتيجة عملية [importlib.import_module] هي وحدة. وبالتالي، بعد السطر 30، تسير الأمور كما لو أن الأمر الذي تم تنفيذه كان:
    import sgbd_connector

    وهذا سيسمح لنا بكتابة السطر 52 [sgbd_connector.connect] حيث نستخدم الدالة [connect] من الوحدة النمطية [sgbd_connector]. يجب أن نتذكر هنا أن [sgbd_connector] هي إما [mysql.connector] أو [psycopg2]. وتحتوي هاتان الوحدتان على الدالة [connect]. وبالمثل، في السطر 60، يمكن كتابة [sgbd_connector.InterfaceError, sgbd_connector.DatabaseError].

    • السطر 32: يتم استيراد الوحدة النمطية التي تحتوي على الوظائف المستخدمة في البرنامج النصي؛
    • السطر 58: يتم تنفيذ الدالة [execute_file_of_commands] من وحدة الدوال المستخدمة في البرنامج النصي. مقارنة بالإصدارات السابقة، تحتوي توقيع هذه الدالة على معلمة إضافية، وهي المعلمة الأولى. يتم تمرير موصل Python [sgbd_connector] إلى الدالة لتستخدمه؛
    • بخلاف هذه النقاط، يظل البرنامج النصي [any_04] كما كان في الإصدارات السابقة؛
