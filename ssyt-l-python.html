    3.1. البرنامج النصي [bases_01]: العمليات الأساسية

    يعرض البرنامج النصي [bases_01] الخصائص الأساسية لـ Python.

    
# ----------------------------------
def affiche(chaine):
    # يعرض سلسلة
    print("chaine=%s" % chaine)


# ----------------------------------
def affiche_type(variable):
    # يعرض نوع المتغير
    print("type[%s]=%s" % (variable, type(variable)))


# ----------------------------------
def f1(param):
    # يضيف 10 إلى param
    return param + 10


# ----------------------------------
def f2():
    # تُرجع مجموعة من 3 قيم
    return "un", 0, 100


# -------------------------------- البرنامج الرئيسي ------------------------------------
# هذا تعليق
# متغير مستخدم دون أن يتم إعلانه
nom = "dupont"

# عرض على الشاشة
print("nom=%s" % nom)

# قائمة تحتوي على عناصر من أنواع مختلفة
liste = ["un", "deux", 3, 4]

# عدد عناصرها
n = len(liste)

# حلقة
for i in range(n):
    print("liste[%d]=%s" % (i, liste[i]))

# تهيئة متغيرين باستخدام توبول
(chaine1, chaine2) = ("chaine1", "chaine2")

# تسلسل السلسلتين
chaine3 = chaine1 + chaine2

# عرض النتيجة
print("[%s,%s,%s]" % (chaine1, chaine2, chaine3))

# استخدام دالة
affiche(chaine1)

# يمكن معرفة نوع المتغير
affiche_type(n)
affiche_type(chaine1)
affiche_type(liste)

# يمكن أن يتغير نوع المتغير أثناء التنفيذ
n = "a changé"
affiche_type(n)

# يمكن للدالة أن تُرجع نتيجة
res1 = f1(4)
print("res1=%s" % res1)

# يمكن للدالة أن تُرجع قائمة من القيم
(res1, res2, res3) = f2()
print("(res1,res2,res3)=[%s,%s,%s]" % (res1, res2, res3))

# كان من الممكن تخزين هذه القيم في متغير
liste = f2()
for i in range(len(liste)):
    print("liste[%s]=%s" % (i, liste[i]))

# اختبارات
for i in range(len(liste)):
    # لا تعرض سوى السلاسل
    if type(liste[i]) == "str":
        print("liste[%s]=%s" % (i, liste[i]))

# اختبارات أخرى
for i in range(len(liste)):
    # يعرض فقط الأعداد الصحيحة الأكبر من 10
    if type(liste[i]) == "int" and liste[i] > 10:
        print("liste[%s]=%s" % (i, liste[i]))

# حلقة while
liste = (8, 5, 0, -2, 3, 4)
i = 0
somme = 0
while i < len(liste) and liste[i] > 0:
    print("liste[%s]=%s" % (i, liste[i]))
    somme += liste[i]  # المجموع=المجموع+القائمة[i]
    i += 1  # i=i+1
print("somme=%s" % somme)

    • السطر 2: الكلمة الرئيسية def تُعرّف دالة؛
    • السطر 2: تتلقى الدالة المعلمة [chaine]. لا يُحدد نوع المعلمة. تستخدم لغة Python التمرير بالقيمة حصريًّا. وتختلف هذه القيمة باختلاف نوع البيانات:
      • بالنسبة للأنواع البسيطة (عدد، قيمة منطقية، ...)، تكون هذه القيمة هي القيمة التي تحتوي عليها البيانات (4، True، ...)؛
      • بالنسبة للأنواع المعقدة (قائمة، فئة...)، تكون هذه القيمة هي عنوان البيانات؛
    • السطران 3-4: محتوى الدالة. يتم إزاحته إلى اليمين بمقدار مسافة تبويب واحدة. هذه المسافة البادئة المرتبطة بالحرف : في الأمر def هي التي تحدد محتوى الدالة. وينطبق هذا على جميع الأوامر التي تحتوي على محتوى: if، else، while، for، try، except؛
    • السطر 4: الصيغة المستخدمة هنا هي [print('text1%F1text2%F2…' % data1, data2)]:
      • تُعد [%Fi] (هنا %s) تنسيقات عرض:
      • %s (string): لسلسلة أحرف؛
      • %d (decimal): للأعداد الصحيحة العشرية الموقعة؛
      • %f (float): تنسيق عشري للأعداد الحقيقية؛
      • %e (exponentiel): تنسيق أسي لعدد حقيقي؛
      • …
    • [data1, data2…] هي التعبيرات التي نريد عرض قيمتها:
      • سيتم عرض [data1] بالتنسيق F1؛
      • سيتم عرض [data2] بالتنسيق F2؛
      • …
    • السطر 10: تدير لغة Python نوع المتغيرات داخليًّا. يمكن معرفة نوع متغير ما باستخدام الدالة type(variable) التي تُرجع متغيرًا من النوع 'type'. التعبير '%s' % (type(variable)) هو سلسلة أحرف تمثل نوع المتغير؛
    • السطر 25: البرنامج الرئيسي. ويأتي هذا البرنامج عادةً (ولكن ليس بالضرورة) بعد تعريف جميع دوال البرنامج النصي. ومحتواه غير مسنن؛
    • السطر 28: في لغة Python، لا يتم إعلان المتغيرات. لغة Python حساسة لحالة الأحرف. المتغير Nom يختلف عن المتغير nom. يمكن وضع سلسلة الأحرف بين علامتي اقتباس " أو علامات الفاصلة العليا '. لذا يمكن كتابة 'dupont' أو "dupont"؛
    • السطر 34: هناك فرق بين التوبول (1,2,3) (لاحظ الأقواس) والقائمة [1,2,3] (لاحظ الأقواس المعقوفة). التوبول غير قابل للتعديل بينما القائمة قابلة للتعديل. في كلتا الحالتين، يُرمز للعنصر رقم i بـ [i]؛
    • السطر 40: range(n) هو التوبول (0,1,2,…,n-1)؛
    • السطر 41: يُستخدم التنسيق %d للأعداد الصحيحة الموقعة؛
    • السطر 74: len(var) هو عدد عناصر المجموعة var (توبول، قائمة، قاموس...)؛
    • السطر 84: تسمح البنية [for in …] بالتكرار على بنية قابلة للتكرار. القوائم والتوابع هي عناصر قابلة للتكرار؛
    • السطر 86: العوامل المنطقية الأخرى هي or و not؛
    • السطر 93: يحسب مجموع الأعداد الأكبر من 0 في القائمة؛

    3.2. نص برمجي [bases_02]: سلاسل التنسيق

    قدمت لغة Python 3 طريقة جديدة لتنسيق سلاسل الأحرف:

    
# سلاسل التنسيق
# التنسيقات هي تلك المستخدمة في لغة C
# عدد صحيح
int1 = 10
print(f"[int1={int1}]")
print(f"[int1={int1:4d}]")
print(f"[int1={int1:04d}]")
# عدد عائم
float1=8.2
print(f"[float1={float1}]")
print(f"[float1={float1:8.2f}]")
print(f"[float1={float1:.3e}]")
# سلسلة
str1="abcd"
print(f"[str1={str1}]")
print(f"[str1={str1:8s}]")
str2="jean de florette"
print(f"[{str2:20.10s}]")
# يمكن تعيين السلاسل المنسقة إلى متغيرات
str3=f"[{str2:20.10s}]"
print(str3)

    صيغة السلسلة المنسقة هي كما يلي:

    1
    f'…{expr1:format1} …. {expr2:format2} ….'

    حيث:

    • [expri]: تعبير؛
    • [formati]: تنسيق التعبير [expri]. هذه التنسيقات هي تلك المستخدمة في لغة C:
      • %d: للأعداد الصحيحة؛
      • %f: الترميز العشري للأعداد الحقيقية؛
      • %e: الترميز الأسي للأعداد الحقيقية؛
      • %s: لسلاسل الأحرف. هذا هو التنسيق المستخدم عندما لا يتم استخدام أي تنسيق لـ [expri]؛
      • %nd، %nf، %ns: يعرض [expri] على n حرفًا: إما أن يتم اقتطاع السلسلة أو استكمالها بمسافات؛
    • السطر 7: [04d]، عدد صحيح مكون من 4 أحرف تم استكمالها من اليسار بأصفار؛
    • السطر 11: [8.2f]، عدد حقيقي عشري مكون من 8 أحرف، منها حرفان بعد الفاصلة؛
    • السطر 12: [.3e]، عدد حقيقي في صيغة أسية مع 3 أرقام عشرية للمانتيسة؛
    • السطر 18: [20.10s]، الأحرف العشرة الأولى من سلسلة تم استكمالها بمسافات لتصل إلى 20 حرفًا؛

    3.3. نص برمجي [bases_03]: تغييرات الأنواع

    نركز هنا على تغييرات الأنواع باستخدام بيانات من نوع str (سلسلة أحرف)، و int (عدد صحيح)، و float (عدد عائم)، و bool (قيمة منطقية).

    
# تغييرات النوع
# int --> str، float، bool
x = 4
print(x, type(x))
x = str(4)
print(x, type(x))
x = float(4)
print(x, type(x))
x = bool(4)
print(x, type(x))

# bool --> int، float، str
x = True
print(x, type(x))
x = int(True)
print(x, type(x))
x = float(True)
print(x, type(x))
x = str(True)
print(x, type(x))

# str → int، float، bool
x = "4"
print(x, type(x))
x = int("4")
print(x, type(x))
x = float("4")
print(x, type(x))
x = bool("4")
print(x, type(x))

# float → str، int، bool
x = 4.32
print(x, type(x))
x = str(4.32)
print(x, type(x))
x = int(4.32)
print(x, type(x))
x = bool(4.32)
print(x, type(x))

# إدارة أخطاء تغيير النوع
try:
    x = int("abc")
    print(x, type(x))
except ValueError as erreur:
    print(erreur)

# حالات متنوعة
x = bool("abc")
print(x, type(x))
x = bool("")
print(x, type(x))
x = bool(0)
print(x, type(x))
x = None
print(x, type(x))
x = bool(None)
print(x, type(x))
x = bool(0.0)
print(x, type(x))

# جميع البيانات هي مثيلات للفئة، وبالتالي لها طرق
# سلسلة أحرف
str1 = "abc"
print(str1.capitalize())
# عدد صحيح
int1 = 4
print(int1.bit_length())
# قيمة منطقية
bool1=True
print(bool1.conjugate())
# عدد حقيقي
float1=8.2
print (float1.is_integer())

    هناك العديد من التغييرات الممكنة في أنواع البيانات. قد تفشل بعضها، مثل تلك الموجودة في السطور 46-47 التي تحاول تحويل السلسلة 'abc' إلى عدد صحيح. وقد تم التعامل مع الخطأ باستخدام بنية try / except. الشكل العام لهذه البنية

    كما يلي:

    
try:
    actions
except Exception as ex:
    actions
finally:
    actions

    إذا أطلقت إحدى إجراءات جملة try استثناءً (أشارت إلى وجود خطأ)، يتم الانتقال فورًا إلى جملة except. إذا لم تطلق إجراءات جملة try أي استثناء، يتم تجاهل جملة except. السمات Exception و ex الخاصة بالأمر except اختيارية. وعندما تكون موجودة، تحدد السمة Exception نوع الاستثناء الذي تم اعتراضه بواسطة الأمر except، بينما تحتوي السمة ex على الاستثناء الذي حدث. قد توجد عدة تعليمات except، إذا أردنا معالجة أنواع مختلفة من الاستثناءات في نفس التعليمات try.

    التعليمات finally اختيارية. إذا كانت موجودة، يتم دائمًا تنفيذ الإجراءات الواردة في finally سواء حدث استثناء أم لا.

    • bool(int i) يساوي False إذا كان i يساوي 0، وTrue في جميع الحالات الأخرى؛
    • bool(float f) يساوي False إذا كان f يساوي 0.0، و True في جميع الحالات الأخرى؛
    • bool(str chaine) تساوي False إذا كانت chaine مكونة من 0 حرف، و True في جميع الحالات الأخرى؛
    • bool(None) تساوي False. None هي قيمة خاصة تعني أن المتغير موجود ولكن ليس له قيمة.

import re


# --------------------------------------------------------------------------
def compare(modèle, chaine):
    # يقارن السلسلة [chaîne] بالنموذج [modèle]
    # عرض النتائج
    print(f"\nRésultats({chaine},{modèle})")
    match = re.match(modèle, chaine)
    if match:
        print(match.groups())
    else:
        print(f"La chaîne [{chaine}] ne correspond pas au modèle [{modèle}]")

      • في النموذج: ^(.*?)(\d+)(.*?)$، سيكون match.groups() توبلاً مكونًا من 3 عناصر نظرًا لوجود ثلاث أقواس؛
    • السطر 21: يُكتب التعبير النمطي الحرفي على النحو r"xxx". الرمز r هو الذي يجعل السلسلة تعبيرًا نمطيًا؛

    تسمح لنا التعبيرات النمطية بفحص تنسيق سلسلة الأحرف. وبذلك يمكننا التحقق من أن السلسلة التي تمثل تاريخًا تكون بالتنسيق jj/mm/aa. وللقيام بذلك، نستخدم نموذجًا ونقارن السلسلة بهذا النموذج. وهكذا، في هذا المثال، يجب أن تكون j و m و a أرقامًا. ونموذج تنسيق التاريخ الصحيح هو «\d\d/\d\d/\d\d»، حيث يشير الرمز \d إلى رقم. الرموز التي يمكن استخدامها في النموذج هي التالية:

    الحرف
    الوصف
    \
    يُشير إلى الحرف التالي على أنه حرف خاص أو حرف حرفي. على سبيل المثال، «n» يمثل الحرف «n»، بينما «\n» يمثل حرف السطر الجديد. التسلسل «\\» يمثل «\»، بينما «\("» يمثل «(».
    ^
    يشير إلى بداية السلسلة.
    $
    يشير إلى نهاية السلسلة.
    *
    يمثل الحرف السابق، صفر مرة أو عدة مرات. وبالتالي، فإن "zo*" يمثل "z" أو "zoo".
    +
    يتطابق مع الحرف السابق، مرة واحدة أو أكثر. وبالتالي، فإن "zo+" يتطابق مع "zoo"، ولكنه لا يتطابق مع "z".
    ?
    يتطابق مع الحرف السابق، صفر أو مرة واحدة. على سبيل المثال، "a?ve?" يتطابق مع "ve" في كلمة "lever".
    .
    يتطابق مع أي حرف فردي، باستثناء حرف السطر الجديد.
    (نموذج)
    يبحث عن modèle ويحفظ المطابقة. يمكن استخراج السلسلة الفرعية المطابقة من المجموعة match.groups(). للعثور على مطابقات تحتوي على أحرف بين قوسين ( )، استخدم "\(" أو "\)".
    x|y
    يتطابق إما مع x أو مع y. على سبيل المثال، "z|foot" يتطابق مع "z" أو مع "foot". "(z|f)oo" يتطابق مع "zoo" أو مع "foo".
    {n}
    n هو عدد صحيح غير سالب. يطابق بالضبط n مضروبًا في الحرف. على سبيل المثال، "o{2}" لا يطابق "o" في "Bob،" بل يطابق الحرفين "o" الأولين في "fooooot".
    {n،}
    n هو عدد صحيح غير سالب. وهو يطابق ما لا يقل عن n ضعف الحرف. على سبيل المثال، لا يتطابق «o{2,}» مع الحرف «o» في كلمة «Bob»، بل مع جميع أحرف «o» في كلمة «fooooot». «o{1,}» يعادل «o+» و«o{0,}» يعادل «o*».
    {n،m}
    m و n هما عددان صحيحان غير سالبين. يعني ظهور الحرف ما لا يقل عن n وما لا يزيد عن m مرة. على سبيل المثال، «o{1,3}» يشير إلى الأحرف «o» الثلاثة الأولى في «foooooot»، و«o{0,1}» يعادل «o?».
    [xyz]
    مجموعة أحرف. تتطابق مع أحد الأحرف المحددة. على سبيل المثال، "[abc]" تتطابق مع الحرف "a" في كلمة "plat".
    [^xyz]
    مجموعة الأحرف السلبية. تتطابق مع أي حرف غير مذكور. على سبيل المثال، "[^abc]" تتطابق مع الحرف "p" في كلمة "plat".
    [a-z]
    نطاق الأحرف. يطابق أي حرف ضمن السلسلة المحددة. على سبيل المثال، "[a-z]" يطابق أي حرف أبجدي صغير بين "a" و"z".
    [^m-z]
    نطاق أحرف سلبي. يطابق أي حرف غير موجود في السلسلة المحددة. على سبيل المثال، "[^m-z]" يطابق أي حرف غير موجود بين "m" و"z".
    \b
    يمثل حدًا يمثل كلمة، أي الموضع بين كلمة ومسافة. على سبيل المثال، "er\b" يمثل "er" في كلمة "lever"، ولكنه لا يمثل "er" في كلمة "verbe".
    \B
    يمثل حدًا لا يمثل كلمة. "en*t\B" يطابق "ent" في "bien entendu".
    \d
    يمثل حرفًا يمثل رقمًا. يعادل [0-9].
    \D
    يمثل حرفًا لا يمثل رقمًا. يعادل [^0-9].
    \f
    يمثل حرف انتقال الصفحة.
    \n
    يمثل حرف السطر الجديد.
    \r
    يُستخدم لتمثيل حرف الرجوع إلى السطر.
    \s
    يمثل أي مسافة بيضاء، بما في ذلك المسافة، وعلامة الجدولة، وعلامة نهاية الصفحة، وما إلى ذلك. يعادل "[ \f\n\r\t\v]".
    \S
    يمثل أي حرف فارغ غير أبيض. يعادل "[^ \f\n\r\t\v]".
    \t
    يمثل حرف الجدولة.
    \v
    يمثل حرف الجدولة العمودية.
    \w
    يتطابق مع أي حرف يمثل كلمة ويتضمن شرطة سفلية. يعادل "[A-Za-z0-9_]".
    \W
    يتطابق مع أي حرف لا يمثل كلمة. يعادل "[^A-Za-z0-9_]".
    \num
    يتطابق مع num، حيث num هو عدد صحيح موجب. يشير إلى المطابقات المخزنة. على سبيل المثال، يتطابق "(.)\1" مع حرفين متطابقين متتاليين.
    \n
    يعادل n، حيث n هو قيمة هروب ثمانية. يجب أن تتألف قيم الهروب الثمانية من 1 أو 2 أو 3 أرقام. على سبيل المثال، "\11" و "\011" كلاهما يعادل حرف الجدولة. "\0011" تعادل "\001" و"1". يجب ألا تتجاوز قيم الهروب الثمانية الرقم 256. إذا تجاوزت هذا الرقم، فلن يؤخذ في الاعتبار سوى أول رقمين في التعبير. تسمح باستخدام الرموز ASCII في التعبيرات النمطية.
    \xn
    تتوافق مع n، حيث n هي قيمة هروب سداسية عشرية. يجب أن تتكون قيم الهروب السداسية العشرية من رقمين على الأقل. على سبيل المثال، "\x41" تعادل "A". و"\x041" تعادل "\x04" و"1". يسمح باستخدام الرموز ASCII في التعبيرات النمطية.

    يمكن أن يظهر عنصر ما في القالب مرة واحدة أو أكثر. لنأخذ بعض الأمثلة حول الرمز \d الذي يمثل رقمًا واحدًا:

    النمط
    المعنى
    \d
    رقم واحد
    \d?
    رقم واحد أو صفر
    \d*
    رقم واحد أو أكثر
    \d+
    رقم واحد أو أكثر
    \d{2}
    رقمان
    \d{3,}
    3 أرقام على الأقل
    \d{5,7}
    ما بين 5 و7 أرقام

    السلسلة المطلوبة
    النموذج

    \s*

    \s*\d+(.\d*)?\s*

    سلسلة تحتوي على الكلمة «just»
    \bjuste\b

    النمط$

    ^النمط$
    يبدأ النموذج السلسلة وينهيها
    النمط

    السلسلة المطلوب البحث عنها

    ^\s*\w+\s*\w+\s*$
    سلسلة تحتوي على الكلمة secret

    يمكن «استخراج» المجموعات الفرعية لنموذج ما. وبالتالي، لا يمكننا فقط التحقق من أن سلسلة ما تتطابق مع نموذج معين، بل يمكننا أيضًا استخراج العناصر من هذه السلسلة التي تتطابق مع المجموعات الفرعية للنموذج والتي تم وضعها بين أقواس. فإذا قمنا بتحليل سلسلة تحتوي على تاريخ بالصيغة يي/شش/سس، وأردنا أيضًا استخراج العناصر يي، شش، سس من هذا التاريخ، فسنستخدم النموذج (\d\d)/(\d\d)/(\d\d).
