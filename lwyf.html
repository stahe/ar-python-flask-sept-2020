    6.1. البرنامج النصي [fonc_01]: نطاق المتغيرات

    يُظهر البرنامج النصي [fonc_01] أمثلة على نطاق المتغيرات بين الدوال:

    
# نطاق المتغيرات
def f1():
    # يجب تجنب استخدام المتغيرات العالمية
    # المتغير العام i
    global i
    i += 1
    # المتغير المحلي j
    j = 10
    print(f"f1[i,j]=[{i},{j}]")


def f2():
    # يجب تجنب استخدام المتغيرات العالمية
    # المتغير العام i
    global i
    i += 1
    # المتغير المحلي j
    j = 20
    print(f"f2[i,j]=[{i},{j}]")


def f3():
    # المتغير المحلي i
    i = 1
    # المتغير المحلي j
    j = 30
    print(f"f3[i,j]=[{i},{j}]")


# البرنامج الرئيسي
i = 0
j = 0
# لن تكون هاتان المتغيرتان معروفتين لدالة f
# إلا إذا أعلنت الدالة صراحةً، باستخدام الأمر global، أنها تريد استخدامهما
# أو إذا كانت الدالة تستخدم المتغير العام للقراءة فقط
f1()
f2()
f3()
# j لم يتغير لكن i تغير
print(f"[i,j]=[{i},{j}]")

    6.3. البرنامج النصي [fonc_03]: نطاق المتغيرات

    يُظهر البرنامج النصي [fonc_03] خاصية مميزة للمتغيرات المستخدمة في كل من الدالة والكود الذي يستدعيها، اعتمادًا على ما إذا كان هذا المتغير يُستخدم في الدالة للقراءة فقط أم لا.

    
def f1():
    # هنا المتغير العام i معروف
    print(f"[f1] i={i}")
    # هنا المتغير العام j معروف
    print(f"[f1] j={j}")


def f2():
    # هنا المتغير العام i غير معروف
    # لأن الدالة f2 تُعرّف متغيرًا محليًّا يحمل نفس الاسم
    # وبالتالي فإن لها الأولوية
    try:
        # محاولة عرض المتغير المحلي i المُعرَّف لاحقًا
        print(f"[f2] i={i}")
        # التعليمة التالية تجعل من i متغيرًا محليًا للدالة f2
        i = 7
    except BaseException as erreur:
        print(f"[f2] erreur={erreur}")


def f3():
    # هنا، المتغير العام i غير معروف
    # لأن الدالة f3 تُعرِّف متغيرًا محليًّا يحمل نفس الاسم
    # وبالتالي فإن لها الأولوية

    # التعليمة التالية تجعل من i متغيرًا محليًّا
    i = 7
    # عرض - هنا تكون i معروفة
    print(f"[f3] i={i}")


# main -----------
# المتغيرات العالمية للدوال
i = 10
j = 20
# استدعاء f1
f1()
print(f"[main] i={i}, j={j}")
# استدعاء f2
f2()
print(f"[main] i={i}")
# استدعاء f3
f3()
print(f"[main] i={i}")

    ملاحظات

    • السطر 34: يحدد الكود الرئيسي متغيرًا [i]؛
    • الأسطر 1-5: تستخدم الدالة f1 أيضًا متغيرًا [i] دون تعيين قيمة له. وهذا يمثل قراءة للمتغير [i]. في هذه الحالة، المتغير [i] المستخدم هو المتغير الموجود في الكود المستدعي، السطر 34؛
    • الأسطر 8-18: تستخدم الدالة f2 أيضًا متغيرًا [i] ولكنها تُعيّن له قيمة في السطر 16. إن تعيين قيمة للمتغير [i] في f2 يجعل تلقائيًّا المتغير [i] متغيرًا محليًّا للدالة [f2]. وبالتالي، فإن هذه الدالة «تخفي» المتغير [i] من الكود المستدعي؛
    • السطر 14: ستفشل عملية كتابة المتغير المحلي [i] لأن هذا المتغير لا يحتوي على قيمة عند الوصول إلى السطر 14. ويحصل على قيمته في السطر 16. وستحدث استثناء. ولهذا السبب، تم إدراج السطر 14 في عبارة try / catch؛

    6.7. النص البرمجي [fonc_07]: استخدام الوحدات النمطية

    يوضح البرنامج النصي [fonc_07] كيفية عزل الدوال في وحدة نمطية.

    نقوم بعزل الوظائف القابلة لإعادة الاستخدام في وحدة نمطية. بدلاً من نقلها من سكريبت إلى آخر:

    • نضعها في ملف منفصل نعلن عنه بطريقة معينة؛
    • تقوم البرامج النصية التي تحتاج إلى هذه الوظائف بـ«استيراد» الوحدة النمطية التي تحتوي عليها؛

    النص البرمجي [fonctions_module_01] هو كما يلي:

    
# الدالة f2
def f2(a, b):
    return f1(a + b)

# الدالة f1
def f1(a):
    return a + 10

    لكي تتمكن البرامج النصية الأخرى من الإشارة إلى وظائف البرنامج النصي [fonctions_module_01]، هناك طرق مختلفة للقيام بذلك. وتختلف هذه الطرق حسب ما إذا كان البرنامج النصي يُنفَّذ داخل [PyCharm] أم لا.

    في [PyCharm]، يتم البحث عن الوحدات المستوردة في مجلدات محددة تسمى [Sources Root]. هناك طريقتان لتحويل مجلد إلى [Sources Root]:

    • في [4]، يتغير لون المجلد؛

    بعد هذه العملية، يتم التعرف على المجلد [fonctions/modules] كمجلد مصدر. يمكن عندئذٍ كتابة ما يلي في البرنامج النصي:

    from fonctions_module_01 import f2

    لاستيراد/استخدام الدالة f2 المُعرَّفة في الوحدة النمطية [fonctions_module_01.py].

    هناك طريقة أخرى تتمثل في استخدام خصائص المشروع:

    • فيما سبق، تسمح التسلسلات [1-6] بتحويل المجلد [shared] إلى مجلد لتخزين الوحدات النمطية المراد استيرادها؛

    ولن نقوم في الوقت الحالي بتعيين أي مجلد مثل [Sources Root] باستثناء المجلد الجذر للمشروع:

    وبعد ذلك، يمكننا كتابة البرنامج النصي [fonc-07] التالي:

    
# استخدام الوحدات النمطية
import sys

# ------------------------ الرئيسي
print(f"Python path={sys.path}")
from fonctions.shared.fonctions_module_01 import f2

print(f2(100, 200))
    • السطر 2: يتم استيراد الكائن [sys] حتى يتسنى استخدام السطر 5، وهو السمة [path] التي تُعطي ما يُسمى بـ [Python Path]: قائمة بالمجلدات التي سيتم استكشافها بحثًا عن الوحدات المستوردة؛
    • السطر 6: يتم استيراد الدالة f2 من الوحدة النمطية [fonctions_module_01]. للإشارة إلى هذه الوحدة النمطية، نستخدم المسار الذي يربط جذر المشروع بالوحدة النمطية. في Pycharm، يكون جذر المشروع دائمًا جزءًا من المجلدات التي يتم استكشافها عند البحث عن وحدة نمطية مستوردة في نص برمجي. وبالتالي، فإن هذا المجلد جزء من [Python Path] الخاص بالمشروع. وهذا ما سيسمح لنا السطر 5 بالتحقق منه؛
    • السطر 6: إذا كنا سنصف المسار الذي يؤدي من جذر المشروع إلى المجلد [fonctions_module_01]، فسنكتب [fonctions/shared/fonctions_module_01]. في مسار الوحدة النمطية، يتم استبدال علامة / بالنقطة. لذا نكتب [fonctions.modules.fonctions_module_01]؛
    • بعد السطر 6، تصبح الدالة f2 معروفة. ونستخدمها في السطر 8؛

    6.9. البرنامج النصي [fonc_09]: إعلان نوع المعلمات

    6.10. نص برمجي [fonc_10]: المعلمات المسماة

    لتمرير المعلمات إلى دالة ما، يمكن استخدام أسماء المعلمات الشكلية لتلك الدالة. في هذه الحالة، ليس من الضروري الالتزام بترتيب المعلمات الشكلية:

    
# يمكن الإشارة إلى المعلمات الفعلية بأسمائها الشكلية
def f(x, y):
    return x + y


# main
print(f(y=10, x=3))

    ملاحظات

    • السطر 2: الدالة f لها معلمتان رسميتان هما x و y؛
    • السطر 7: عند استدعاء الدالة f، يمكن استخدام أسماء المعلمات الشكلية. قد تكون هذه الممارسة مفيدة في حالتين على الأقل:
      • تحتوي الدالة على العديد من المعلمات التي يكون لمعظمها قيمة افتراضية. عند الاستدعاء، تسمح التقنية السابقة بتهيئة المعلمات التي لا نريد استخدام قيمتها الافتراضية فقط؛
      • إذا كانت المعلمات الشكلية تحمل أسماء ذات معنى، فإن استخدام المعلمات المسماة عند استدعاء الدالة يحسّن قابلية قراءة الكود؛

    6.11. النص البرمجي [fonc_11]: دالة متكررة

    النص البرمجي [fonc_11] هو مثال على دالة متكررة (تستدعي نفسها):

    
# دالة متكررة
def fact(i: int) -> int:
    # العدد التوافقي (1) يساوي 1
    # يجب أن تنتهي الدالة التكرارية في وقت ما
    if i == 1:
        return 1
    else:
        # العدد التوافقي(i) = i * العدد التوافقي(i-1)
        return i * fact(i - 1)


# ---------- main
print(f"fact(8)={fact(8)}")

    6.12. نص برمجي [fonc_12]: دالة متكررة

    تقدم الدالة [fonc_12] مزيدًا من التفاصيل حول كيفية عمل التكرار:

    
# دالة متكررة
# سلوك المعلمة j


def fact(i: int, j: int) -> int:
    # توقف الدالة التكرارية
    if i == 1:
        print(f"j={j}")
        return 1
    else:
        # معالجة j
        j += 1
        print(f"avant fact j={j}")
        # التكرار
        f = fact(i - 1, j)
        print(f"après fact j={j}")
        # النتيجة
        return i * f


# ---------- main
print(f"fact(8)={fact(8, 0)}")
