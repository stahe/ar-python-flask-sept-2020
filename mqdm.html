    الأمثلة الواردة في هذا المستند متاحة |HERE|.

    يقدم هذا المستند قائمة ببرامج Python النصية في مجالات مختلفة:

    • أساسيات اللغة؛
    • إدارة قواعد البيانات MySQL و PostgreSQL؛
    • برمجة الشبكات TCP/ IP (بروتوكولات HTTP، POP3، IMAP، SMTP)؛
    • برمجة الويب MVC باستخدام إطار العمل FLASK؛
    • البنى ثلاثية الطبقات والبرمجة عبر الواجهات؛

    هذه ليست دورة شاملة في لغة Python، بل هي مجموعة من الأمثلة الموجهة للمطورين الذين سبق لهم استخدام لغة برمجة نصية مثل Perl أو PHP، أو VBScript، أو المطورين المعتادين على اللغات المحددة الأنواع مثل Java أو C# والذين قد يكونون مهتمين باكتشاف لغة برمجة نصية موجهة للكائنات. هذا المستند غير مناسب للقراء الذين لم يسبق لهم البرمجة أو الذين لديهم خبرة محدودة في هذا المجال.

    كما أن هذا المستند ليس مجموعة من «الممارسات الجيدة». وقد يجد المطور المتمرس أن بعض الأكواد يمكن كتابتها بشكل أفضل. الهدف الوحيد من هذا المستند هو تقديم أمثلة لمن يرغب في التعرف على لغة Python 3 وإطار العمل Flask. ويمكنه بعد ذلك تعميق معرفته من خلال مستندات أخرى.

    تحتوي البرامج النصية على تعليقات، كما يتم عرض نتائج تنفيذها. وفي بعض الأحيان، يتم تقديم تفسيرات إضافية. يتطلب هذا المستند قراءة نشطة: لفهم البرنامج النصي، يجب قراءة الكود والتعليقات ونتائج التنفيذ معًا.

    الأمثلة الواردة في هذا المستند متاحة على الرابط |HERE|:

    هذه الوثيقة هي تحديث لوثيقة سابقة صدرت في يونيو 2011 |https://tahe.developpez.com/tutoriels-cours/python/|. وقد تم إنشاء وثيقة عام 2011 باستخدام مترجم Python 2.7. ومنذ ذلك الحين، ظهرت إصدارات Python 3.x. في فبراير 2020، وصلنا إلى الإصدار 3.8. وقد تسببت إصدارات 3.x في انقطاع في قابلية التوافق بين الإصدارات: فقد يتبين أن الأكواد التي تعمل في Python 2.7 غير قابلة للاستخدام في Python 3.x. وينطبق هذا بشكل خاص على الكتابة في وحدة التحكم. في الإصدار 2.7، يمكن كتابة [print "toto"]، بينما في الإصدار 3.x يجب كتابة [print("toto")]: يجب إضافة أقواس. هذا التغيير البسيط يجعل معظم الأكواد المرفقة مع الوثيقة الصادرة عام 2011 غير قابلة للاستخدام مباشرةً مع Python 3.x. لذا يجب تعديلها.

    لا يقتصر هذا المستند الجديد على تحديث أكواد عام 2011 لتصبح قابلة للتنفيذ مع Python 3.8 فحسب:

    • فقد شهدت الأقسام المتعلقة بالبرمجة TCP-IP واستخدام قواعد البيانات تطورات مهمة؛
    • أما القسم الخاص ببرمجة الويب، الذي كان مجرد مقدمة، فقد أصبح الآن دورة تدريبية كاملة تستخدم إطار العمل FLASK؛

    لإنشاء هذه الدورة التدريبية، اتبعت نهجًا غير معتاد: قمت بتحويل الدورة التدريبية PHP [Introduction au langage PHP7 par l’exemple]. لذا لم أتبع الهياكل التقليدية لدورات Python أو Flask. كنت أرغب قبل كل شيء في معرفة كيف يمكنني القيام في Python 3 بما قمت به في PHP 7. وكانت النتيجة أنني تمكنت من إعادة إنشاء جميع أمثلة الدورة التدريبية PHP 7 باستخدام Python 3 / Flask.

    قد يحتوي هذا المستند على أخطاء أو نواقص. يمكن للقارئ استخدام سلسلة المناقشة |forum| للإبلاغ عنها.
