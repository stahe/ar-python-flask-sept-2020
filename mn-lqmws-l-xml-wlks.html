    26. من القاموس إلى XML والعكس

    نقترح هنا استكشاف الوحدة النمطية [xml2dict] التي تسمح بتحويل:

    • سلسلة XML إلى قاموس:
    • قاموس إلى سلسلة XML؛

    قبل ظهور jSON، كانت استجابة خدمات الويب غالبًا بتنسيق XML (لغة ترميز eXtended). من ناحية أخرى، كان بروتوكول خدمات الويب هذه غالبًا SOAP (بروتوكول معالجة الكائنات البسيطة). SOAP هو بروتوكول يعتمد على بروتوكول الويب HTTP. حاليًّا (2020)، تكون خدمات الويب في الغالب من النوع REST (نقل الحالة التمثيلية). خدمات الويب التي درسناها لا تنتمي إلى أي من هذه الأنواع، لكنها بالتأكيد أقرب إلى REST منها إلى SOAP. ومع ذلك، أفضّل وصفها بأنها من النوع «الحر» أو «المجهول» لأنها لا تتوافق مع جميع قواعد REST.

    سنوضح مدى سهولة تحويل بنى العميل/الخادم jSON الخاصة بنا إلى بنى العميل/الخادم XML. يكفي استخدام الوحدة النمطية [xmltodict].

def transform(message: str, dictionary: dict):
    # السجلات
    print(f"\n{message}-------")
    print(f"dictionnaire={dictionary}")
    # القاموس -> xml
    xml1 = xmltodict.unparse(dictionary)
    print(f"xml={xml1}")
    # xml -> OrderedDict
    ordereddict_dictionary1 = xmltodict.parse(xml1)
    print(f"ordereddict_dictionary1={ordereddict_dictionary1}")
    # OrderedDict -> قاموس
    print(f"dict_dictionary1={ordereddict2dict(ordereddict_dictionary1)}")

      • السطر 23: القيم المرتبطة بمفاتيح القاموس [result] هي أرقام؛

    لنركز الآن على الطريقة [ordereddict2dict] التي تحول النوع [OrderedDict] إلى النوع [dict]:

    
# xmltodict.parse للانتقال من XML إلى القاموس. يجب أن يكون للقاموس جذر
# القاموس الناتج من النوع OrderedDict
# xmltodict.unparse للانتقال من القاموس إلى XML

def check(value):
    # إذا كانت القيمة من النوع OrderedDict، يتم تحويلها
    if isinstance(value, OrderedDict):
        value2 = ordereddict2dict(value)
    # إذا كانت القيمة من النوع «قائمة»، يتم تحويلها
    elif isinstance(value, list):
        value2 = list2list(value)
    else:
        # نكون أمام نوع بسيط وليس مجموعة
        value2 = value
    # نُرجع القيمة الجديدة
    return value2


def list2list(liste: list) -> list:
    # القائمة الجديدة
    newliste = []
    # نستخرج عناصر القائمة المعلمة
    for value in liste:
        # نضيف القيمة إلى القائمة الجديدة
        newliste.append(check(value))
    # نُرجع القائمة الجديدة
    return newliste


def ordereddict2dict(ordered_dictionary: OrderedDict) -> dict:
    # OrderedDict -> القاموس بطريقة متكررة
    newdict = {}
    for key, value in ordered_dictionary.items():
        # يتم تخزين القيمة في القاموس الجديد
        newdict[key] = check(value)
    # نُرجع القاموس
    return newdict
